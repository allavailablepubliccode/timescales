# Derived data

`pc1_variances.csv` contains the participant-level PC1 variances used in the manuscript's intact-versus-sentence-scrambled comparison.

Columns:
- `subject`: participant index (1–24)
- `var_intact_pc1`: PC1 variance in the intact condition
- `var_scram_pc1`: PC1 variance in the sentence-scrambled condition

These are derived values, not raw fMRI data. The raw data are available from OpenNeuro dataset ds002345.
